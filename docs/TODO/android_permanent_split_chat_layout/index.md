# Android 常驻双栏聊天界面改造

## 原本状况

手机宽度使用可滑出的抽屉导航，平板宽度才显示可伸缩侧边栏。主内容顶部栏使用状态栏 inset，导致界面结构与系统状态栏脱离。

## 修正意图

- 手机竖屏使用手势滑出的侧边栏，聊天主页面保持全宽且不参与抽屉动画。
- 平板和横屏继续使用常驻侧边栏。
- Activity 使用 edge-to-edge，页面背景延伸至状态栏下方。
- 聊天内容继续由既有 `AppContent` 与 `AIChatScreen` 承载，避免改变聊天业务状态。

## 作用域

`MainActivity` 的窗口配置、主布局选择、新双栏布局组件以及对应 TODO 文档。

## 期待结果

在安卓竖屏上，左栏和聊天页始终同时可见；系统状态栏覆盖在内容背景上，控件各自处理所需 inset。
